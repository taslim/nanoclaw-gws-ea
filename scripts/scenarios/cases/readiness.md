## Exercising real web reads safely

Native WebSearch and WebFetch can be measured with an invented principal, an
invented task and native synthetic whereabouts while reading real public venue
information. Public source data need not be invented for the task data to stay
synthetic. Keep Google/mail/people state on the closed native fake host, allow
only these read tools for selected cases, and record their exact queries, URLs,
results and any model/tool cost for the judge. Freeze the captured public source
facts with each evidence run; before/after runs need the same source conditions,
or must disclose the change. Never send a real person's plans, address, account
identity or private context in a query.

That route has not been enabled or probed here. WebSearch's upstream results
cannot be safely replaced by a fabricated successful search. To require wholly
invented web content while still exercising native WebFetch, first provide an
owned, publicly reachable synthetic fixture page (or a proven native fetch
transport interception with equivalent URL/security behavior). Localhost/RPC
substitution or a PreToolUse fake result would not prove the normal public fetch
path. WebSearch would still need a separately proven search transport or live
public evidence. Keep these cases unavailable until the chosen boundary is
verified; do not silently replace their search request with a store lookup.

Authenticated Claude Code adds account-email metadata to model context. The
previous smoke observed it in a misdirected calendar query. This remains an
isolation limitation: raw evidence stays local, summaries omit the address,
and no such metadata may be forwarded into a web query.
