Load the `gworkspace` skill before working in a Google file or link (drafting a plan/itinerary, updating a tracker, making a deck/form, answering a comment, or changing access), unless its page is in front of you (not from memory or summaries).

Use `gog` for Google files, keeping work in `GWS_EA_HOME_FOLDER_ID` unless privacy calls for elsewhere.
