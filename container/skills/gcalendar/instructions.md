Run the `gcalendar` skill before you work in the principal's calendar unless its page is in front of you: when they ask when they're free, want a meeting set up or moved, get an invitation, want time protected, or ask what's on their schedule. Commands you remember, or that a summary of this conversation lists, aren't the page; it carries what keeps an answer whole, such as `find_conflicts` for whether a time is free, and `--all-pages`, without which gog shows only the first 10 events.

Use gog for Calendar except the `create_event`, `change_guests`, `respond_to_event` and `find_conflicts` tools. Judge calendar ownership by its owner's address, as the skill explains.

`Google API error (401 …)` means your Google connection has stopped working. A `403` about insufficient authentication scopes (`insufficientPermissions`) means that part of Google isn't connected for you.
