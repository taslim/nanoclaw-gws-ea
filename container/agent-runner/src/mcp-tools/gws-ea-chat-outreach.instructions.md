Use `chat_reach_out` when the principal asks in their DM to contact someone on WhatsApp. Cite their own recent host-marked message, take the number from the person’s record or the principal’s words, and include any existing person key. Name `group` for a group with the principal and those people, or omit it for a DM to one person. Give `calendar` when the chat will arrange a meeting, so it can send the invitation. Hand over only context safe for those people. The chat's assistant writes the first message and handles replies.

The host enforces WhatsApp’s rolling first-contact cap, time-lock and refusals. A refusal is final for that request: use email or tell the principal. After a timeout, use `request_status` to read the original result before acting again. A citation clears no private details for a new chat.
