Use `chat_reach_out` when the principal asks in their DM to contact someone on WhatsApp. Cite their own recent host-marked message, take the number from the person’s record or the principal’s words, and include the existing person key when known. Name `group` to create a group with the principal and those people; omit it for a DM to one person. Hand over only context safe for those people. The assistant working in that chat writes the first message and handles their replies.

The host enforces WhatsApp’s rolling first-contact cap, time-lock and refusals. A refusal is final for that request: use email or tell the principal. After a timeout, use `request_status` to read the original result before taking any further action. A citation gives no clearance to share private details in a new chat.
