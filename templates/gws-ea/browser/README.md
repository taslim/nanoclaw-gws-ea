# GWS-EA browser

The host stamps this sealed tool group once when the operator enables the browser. Only the agent groups the operator's browser-access setting lists delegate work to it, each through a native per-thread destination; that is main unless the setting names others. Every errand has its own provider state and no shared memory. The host supplies the exact capabilities, model and CLI scope and refuses drift at session admission. The release supplies instructions.md as a required project-document section.
